---
name: prepare
description: Load durable project context before a fresh Ralph pass.
---

Study the project before taking action.

1. Read the project README when present.
2. Read contributor or developer guidance when present.
3. Read the documentation index when present.
4. Inspect the current version-control status without discarding or overwriting unrelated work.
5. Treat durable project files as authoritative and state uncertainty when required context is unavailable.

Do not select a Ralph phase, create planning documents, or begin execution merely because this skill was loaded.
